# Keytomic Integration Guide (Next.js App Router)

## Overview
This document explains how to integrate the Keytomic headless CMS into a Next.js (App Router) application to automate blog content generation and optimize Search Engine Optimization (SEO). It is based on a production implementation and serves as a reference for implementing Keytomic in other websites.

## Architecture & Framework
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **SDK:** `@keytomic/sdk` (Requires installation: `npm install @keytomic/sdk`)
- **Core Integration File:** `src/lib/keytomic.ts`

## 1. Keytomic SDK Initialization
The Keytomic SDK should be configured centrally. It authenticates using the `KEYTOMIC_API_KEY` environment variable and exports wrapper functions to interact with the Keytomic API.

**Implementation (`src/lib/keytomic.ts`):**
```typescript
import {
  getHealth,
  listBlogs,
  getBlogById,
  getBlogBySlug,
  type GetHealthResult,
  type ListBlogsResult,
  type GetBlogByIdResult,
  type GetBlogBySlugResult,
} from '@keytomic/sdk'

const getHeaders = () => {
  if (!process.env.KEYTOMIC_API_KEY) {
    throw new Error('KEYTOMIC_API_KEY is not defined')
  }
  return {
    Authorization: `Bearer ${process.env.KEYTOMIC_API_KEY}`,
  }
}

export const keytomic = {
  getHealth: (): Promise<GetHealthResult> => {
    return getHealth({ headers: getHeaders() })
  },
  listBlogs: (limit?: number, cursor?: string): Promise<ListBlogsResult> => {
    return listBlogs({
      query: { limit, cursor },
      headers: getHeaders(),
    })
  },
  getBlogById: (id: string): Promise<GetBlogByIdResult> => {
    return getBlogById({
      path: { id },
      headers: getHeaders(),
    })
  },
  getBlogBySlug: async (slug: string) => {
    try {
      const detailRes = await getBlogBySlug({
        query: { slug },
        headers: getHeaders(),
      })
      return detailRes.data.data
    } catch (err: any) {
      if (err?.response?.status === 404) return null
      throw err
    }
  },
}
```

## 2. Blog Content Auto-Generation
The website dynamically generates blog pages by fetching data directly from Keytomic.

### Blog Listing Page (`src/app/blog/page.tsx`)
The blog index page fetches a paginated list of blog posts using `keytomic.listBlogs(limit, cursor)`. It implements cursor-based pagination for "Load More" functionality, utilizing `result.data.pageInfo.nextCursor` and `result.data.pageInfo.hasMore`.

### Blog Detail Page (`src/app/blog/[slug]/page.tsx`)
Individual blog posts are dynamically generated based on the URL slug. The rich text content generated by Keytomic is rendered directly into the page using React's `dangerouslySetInnerHTML`.

```tsx
// Example rendering of Keytomic HTML content
<div 
  className="blog-content"
  dangerouslySetInnerHTML={{ __html: blog.html }}
/>
```

## 3. SEO Optimization Implementation
The application heavily leverages the SEO data provided by the Keytomic API to maximize search engine visibility.

### Dynamic Metadata & Open Graph
Next.js's `generateMetadata` function is used to dynamically populate the `<head>` tags for each blog post based on Keytomic data:

```tsx
// src/app/blog/[slug]/page.tsx
import { Metadata } from 'next'
import { keytomic } from '@/lib/keytomic'

export async function generateMetadata({ params }: { params: { slug: string } }): Promise<Metadata> {
  const blog = await keytomic.getBlogBySlug(params.slug)
  if (!blog) return { title: 'Not Found' }
  
  return {
    title: blog.seo.metaTitle || blog.title,
    description: blog.seo.metaDescription || blog.excerpt || '',
    alternates: {
      canonical: blog.seo.canonicalUrl || `https://yourdomain.com/blog/${blog.slug}`,
    },
    openGraph: {
      title: blog.seo.metaTitle || blog.title,
      description: blog.seo.metaDescription || blog.excerpt || '',
      url: `https://yourdomain.com/blog/${blog.slug}`,
      type: 'article',
      publishedTime: blog.publishedAt,
      modifiedTime: blog.updatedAt,
      images: blog.coverImageUrl ? [{ url: blog.coverImageUrl }] : [],
    },
  }
}
```

### Automated Dynamic Sitemap (`src/app/sitemap.ts`)
The `sitemap.xml` is dynamically generated by paginating through all available Keytomic blogs.

**Helper function in `src/lib/keytomic.ts`:**
```typescript
export async function getAllKeytomicBlogsForSitemap() {
  let allBlogs: any[] = []
  let cursor: string | undefined = undefined
  let hasMore = true

  while (hasMore) {
    const result = await keytomic.listBlogs(50, cursor)
    const blogs = result.data.data
    const pageInfo = result.data.pageInfo
    
    allBlogs = [...allBlogs, ...blogs]
    hasMore = pageInfo.hasMore
    cursor = pageInfo.nextCursor || undefined
  }

  return allBlogs.map((blog) => ({
    slug: blog.slug,
    updatedAt: blog.updatedAt,
    publishedAt: blog.publishedAt,
    createdAt: blog.createdAt,
  }))
}
```

**Sitemap Generation (`src/app/sitemap.ts`):**
```typescript
import { MetadataRoute } from 'next'
import { getAllKeytomicBlogsForSitemap } from '@/lib/keytomic'

// Ensure the sitemap is auto-generated dynamically and not cached statically
export const dynamic = "force-dynamic"
export const revalidate = 0

export default async function sitemap(): Promise<MetadataRoute.Sitemap> {
  const blogs = await getAllKeytomicBlogsForSitemap()
  
  const blogPages: MetadataRoute.Sitemap = blogs.map((blog) => {
    const lastModifiedDate = blog.updatedAt || blog.publishedAt || blog.createdAt || new Date().toISOString()
    
    return {
      url: `https://yourdomain.com/blog/${blog.slug}`,
      lastModified: new Date(lastModifiedDate),
      changeFrequency: 'weekly',
      priority: 0.8,
    }
  })

  return [...blogPages] // Combine with static pages
}
```
